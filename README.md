# Прогноз нагрузки на рекрутинг IT-департаментов

Pet-проект по прогнозированию потока кандидатов на 2025-2027 годы для IT-департаментов крупной компании, с использованием Ridge-регрессии и walk-forward валидации.

## О проекте

У компании 505 IT-департаментов (аэропорты, стадионы, вокзалы, торговые центры и т.д.), и рекрутинг заранее не знает, сколько резюме придётся обработать в следующие годы. Нужно спрогнозировать суммарный поток кандидатов на 2025-2027 годы, чтобы заранее спланировать нагрузку на рекрутеров.

Цель проекта - построить модель, предсказывающую `yearly_cv_processed` (количество обработанных резюме за год на департамент) по HR-метрикам департамента: численности персонала, количеству активных проектов, бюджету на зарплаты и другим показателям.

Это pet-проект, но выполнен по стандартам, приближенным к продовым, - по тому же принципу, что и предыдущий мой pet-проект [churn-teledom](https://github.com/and1cod/churn-teledom): очистка данных и разведочный анализ остаются в ноутбуке как есть - виден ход рассуждений и код каждого исправления, а в модули `src/` вынесено то, что не привязано к рассказу о конкретном датасете - загрузка данных, визуализация и обучение модели.

**Датасет:** HR-метрики 505 IT-департаментов за 2020-2024 гг. (2 525 строк, 14 признаков). **Целевая переменная:** `yearly_cv_processed` - количество обработанных резюме за год.

## Организация кода

Проект сознательно совмещает два подхода. Разведочный анализ, подготовка данных и выводы остаются в ноутбуке - так виден ход рассуждений и обоснование каждого решения. Переиспользуемый и объемный код вынесен в модули src/:

`config.py` - единое место для путей, списков признаков (`CAT_FEATURES`, `NUM_FEATURES`) и схемы walk-forward валидации (`CV_FOLDS`)

`data.py` - загрузка csv (`load_data`)

`eda.py` - функции для разведочного анализа, по аналогии с `overview()` из churn-teledom: `overview(df)` - сводка по датафрейму (дубликаты, типы, пропуски, уникальные значения)

`viz.py` - распределение категориального признака горизонтальным баром с долями, числового - гистограмма с KDE/средним/медианой и ящик с усами с подписанными квартилями, тепловая карта корреляций, график исторических данных с прогнозом. `visualize_categorical_overview`/`visualize_numeric_overview` проходят по всем столбцам датафрейма, вызывая `visualize_categorical`/`visualize_numeric` для каждого - те же две функции переиспользуются поколоночно

`modeling.py` - построение матрицы признаков (OHE + масштабирование без утечек между train/test), walk-forward кросс-валидация (`run_cv`), обучение финальной модели (`train_final_model`) и итеративный прогноз на несколько лет вперёд, где предсказание года t становится лаговым признаком для t+1 (`forecast_future`). Также feature engineering (лаги, дельты)

## Ключевые находки

**Очистка данных**

Пропуски были в 10 из 14 колонок - заполнены медианой по департаменту. Отдельно восстановлены значения `devs_fired` для одного департамента через уравнение баланса штата (`staff(t-1) + hired(t) - staff(t)`). Пересчитан `turnover_rate` по формуле `(devs_fired + devs_hired) / current_staff_count` - в исходных данных она была рассчитана иначе и давала невозможные нулевые значения. Два аномальных выброса в `inbound_applications` (заявки от учебных заведений, в разы превышающие норму) заменены медианой по департаменту

**EDA**

Целевая переменная растёт с 2020 по 2024 годы, но темп затухающий: +5,4% в 2021 году против +1,3% в 2024. Сильнее всего с целевой коррелируют количество активных проектов, численность персонала и бюджет на зарплаты - логично, поскольку больше проектов требует больше сотрудников, а значит и больше обработанных резюме

**Модель**

Ridge-регрессия (устойчива к мультиколлинеарности между признаками) с walk-forward валидацией (train всегда предшествует test по времени):

| Год теста | MAE | R² |
|-----------|-----|----|
| 2022 | ~54 | 0.996 |
| 2023 | ~57 | 0.996 |
| 2024 | ~55 | 0.997 |

Средняя ошибка ≈ 55 резюме при медиане 2 000 - погрешность около 2,7%. Сильнее всего на прогноз влияет лаговое значение самой целевой переменной, за ним - динамика активных проектов (дельта и лаг) и чистый прирост штата.

**Прогноз 2025-2027**

Итеративный прогноз (предсказание года становится лаговым признаком для следующего):

| Год | CV (сумма) | Прирост |
|-----|-----------|---------|
| 2024 (факт) | 1 126 493 | - |
| 2025 | 1 137 011 | +10 518 |
| 2026 | 1 147 248 | +10 237 |
| 2027 | 1 157 212 | +9 964 |

## Итог

Рекрутинговая нагрузка продолжит умеренно расти - примерно на 10 тысяч резюме в год, темп роста при этом замедляется, что согласуется с исторической динамикой.
